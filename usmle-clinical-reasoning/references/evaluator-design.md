## `OPT-66-USMLE` evaluator

**Primary evidence:** educational case orientation, problem representation, cue / hypothesis ledger, information plan, safety / supervision record, handoff, reassessment.

**Dimensions:** evidence fidelity; problem representation; differential reasoning; information purpose; safety; supervision; uncertainty; communication; reassessment.

**Critical failures:** real-patient care instruction, invented clinical finding, unsafe action without escalation, privacy breach, or outdated guidance presented as current.

**Challenge set design:** missing cue; competing hypotheses; test with unclear purpose; safety-critical deterioration; handoff with incomplete information; refusal / escalation case.

**Improvement loop:** diagnose premature closure or missing safety → revise case-reasoning prompt → rerun on a different educational case → clinician / educator reviews.
